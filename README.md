At work I look after the network and servers of an office of about forty people, automate internal processes, and write software for a building automation product.

## What is here

**Network and systems**

- [mikrotik-change-tools](https://github.com/alexpitea/mikrotik-change-tools) - Python tool for router changes that can always be undone: plan, backup, snapshot, apply, rollback
- [windows-workstation-setup](https://github.com/alexpitea/windows-workstation-setup) - PowerShell scripts for preparing and checking office workstations, all previewable with `-WhatIf`
- [windows-server-on-lxd](https://github.com/alexpitea/windows-server-on-lxd) - Windows Server 2022 that installs itself inside an LXD virtual machine, with backups, without root
- [sysadmin-case-studies](https://github.com/alexpitea/sysadmin-case-studies) - anonymised write-ups of outages I diagnosed and changes I rolled out

**Automation and AI integrations**

- [n8n-selfhosted-stack](https://github.com/alexpitea/n8n-selfhosted-stack) - self-hosted n8n that stays up on its own: tested backups, recovery after reboot, approval rules in SQL

- [warehouse-mcp-demo](https://github.com/alexpitea/warehouse-mcp-demo) - MCP server that gives an AI assistant read and write tools over a warehouse back end, with profiles and retry-safe writes

**C++ on the Windows API**

- [Secure-Password-Vault](https://github.com/alexpitea/Secure-Password-Vault) - command-line password manager: AES-256-GCM, PBKDF2, SQLite with prepared statements
- [Fast-Port-Scanner](https://github.com/alexpitea/Fast-Port-Scanner) - multithreaded TCP scanner with connection timeouts
- [System-Resource-Monitor](https://github.com/alexpitea/System-Resource-Monitor) - console dashboard for CPU, memory and processes
